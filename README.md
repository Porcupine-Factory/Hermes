# Hermes
The Hermes Gem handles sending arbitrary data between server and clients.

O3DE Hermes Gem is licensed under [MIT](LICENSE.txt).

## Adding a New Component
Simply run `addac.sh` in a Bash shell and follow its instructions to create a new regular component along with a new networking auto-component.

## Installation Instructions
You can install this gem in your project using O3DE's project manager. Navigate to the Gem Repositories page and provide this URL:

`https://gitlab.com/porcupine-factory/Hermes/-/raw/games/FirstGame`

Alternatively, clone this repo, register the gem with `scripts\o3de register --gem-path <path-to-gem>`, and enable it in your project.
